# AWS_Python_data_analysis

Olist のブラジル EC データを用いて、低評価レビューのリスクを分析・予測し、その要因と将来の購買・GMVとの関係を検証するデータ分析ポートフォリオです。
AWS（Amazon S3 / Athena）と SQL で分析用データを作成し、Python（Positron, VS Code / Jupyter Notebook）で統計分析・機械学習・売上構造分析を行っています。

## 1. 分析で明らかにしたいこと

> **注文・配送・商品・地域情報から低評価になりやすい注文を識別し、
> その要因や対象セグメントを理解したうえで、
> 低評価とその後の再購入・将来 GMV の関係を明らかにできるか。**

本プロジェクトは、次の2段階で進めます。

1. **予測分析**
   - 低評価レビュー（1〜2点）の予測
   - Baseline モデルから追加特徴量を加えた Improved モデルへの改善
   - 将来期間を用いた時系列 Holdout 評価

2. **ビジネスへの影響分析**
   - 低評価 / 高リスク注文と、その後の再購入・注文数・将来 GMV との関係を確認
   - 施策効果そのものではなく、低評価対策が関係しうる売上規模・顧客行動を定量的に把握

> **注意**
> Olist データは観察データであり、介入実験の結果は含まれていません。
> そのため、本プロジェクトでは「施策によって GMV が増加する」といった因果効果は直接推定しません。

## 6. 主な分析結果

### 6.1 注文金額・送料とレビュー評価

注文に複数の商品が含まれることを考慮し、商品明細を注文単位に集約してからレビュー情報と結合しました。

| Variable | Kruskal–Wallis H | p-value | ε² |
|---|---:|---:|---:|
| Total Price（価格） | 299.1710 | < 0.001 | 0.003015 |
| Total Freight （送料）| 932.2902 | < 0.001 | 0.009481 |

統計的な差は確認されましたが、効果量は小さく、**大規模サンプルでは p 値だけでなく効果量も確認する必要がある**ことを確認しました。

Notebook: [`1_review_price_analysis.ipynb`](notebooks/1_review_price_analysis.ipynb)

### 6.2 配送遅延とレビュー評価

```text
配送遅延日
= 実際の配送日 - 配送予定日
```

- 負の値: 予定より早く配送
- 0: 予定どおり
- 正の値: 予定より遅く配送

分析対象は 95,830 注文です。

| レビュー評価 | 配送遅延中央値 |
|---:|---:|
| 1 | -7 days |
| 2 | -10 days |
| 3 | -11 days |
| 4 | -12 days |
| 5 | -13 days |

- Kruskal–Wallis: H = 3890.1397, p < 0.001
- ε² = 0.040555
- Dunn 検定では全レビュー評価群間で有意差
- Review 1 vs 5 のペアでは中程度の効果量（δ = 0.3710）を確認

低評価の注文ほど、予定配送日との差が遅延側に位置する傾向が確認されました。

ただし、これは観察データ上の関連であり、配送遅延が低評価を引き起こしたことを示すものではありません。

Notebook: [`2_review_delivery_analysis.ipynb`](notebooks/2_review_delivery_analysis.ipynb)

### 6.3 低評価と90日以内の再購入・将来GMV

レビュー投稿後90日間の購買行動を追跡可能な74,185件の注文を対象に、低評価と将来の顧客行動の関連を分析しました。

低評価はレビュー評価1〜2点、通常評価は3〜5点と定義しました。

#### 90日以内の再購入率

| 指標 | 通常評価 | 低評価 |
|---|---:|---:|
| 対象注文数 | 63,206 | 10,979 |
| 再購入注文数 | 790 | 104 |
| 再購入率 | 1.2499% | 0.9473% |

Fisherの正確確率検定では、低評価群の再購入率が統計的に有意に低い結果でした。

- オッズ比：0.756
- p値：0.00685
- 再購入率の差：-0.303ポイント

さらに、購入時期・過去の注文回数・配送完了状況を調整したロジスティック回帰を実施しました。

同一顧客による複数観測を考慮し、顧客単位のクラスターロバスト標準誤差を使用しました。

- 調整オッズ比：0.742
- 95%信頼区間：0.587〜0.938
- p値：0.0126

調整後も、低評価と90日以内の再購入には統計的に有意な負の関連が認められました。

#### 90日以内の将来GMV

GMVは送料を含まない商品価格の合計として集計しました。

| 指標 | 通常評価 | 低評価 |
|---|---:|---:|
| 全注文の平均将来GMV（BRL） | 1.663 | 1.505 |
| 再購入ありの平均将来GMV（BRL） | 133.03 | 158.87 |

将来GMVは約98.8%の注文で0となるため、平均差をブートストラップで評価しました。

顧客単位クラスターブートストラップ（2,000回）の結果：

| 分析対象 | 平均GMV差（低評価−通常評価） | 95%信頼区間 |
|---|---:|---|
| 全注文 | -0.158 BRL | -0.655〜0.430 |
| 再購入あり | +25.843 BRL | -12.247〜73.609 |

いずれも95%信頼区間に0を含み、平均将来GMVの明確な群間差は確認できませんでした。

#### ビジネス上の示唆

低評価群では90日以内の再購入率が有意に低かった一方、将来GMVの平均差は統計的に明確ではありませんでした。

このため、低評価予測モデルは顧客フォロー対象の優先順位付けへの活用を想定しています。ただし、対応施策によって再購入率やGMVが改善するかどうかは、別途介入効果の検証が必要です。

Notebook: `12_low_review_future_purchase_analysis.ipynb`

## 7. 低評価予測の基準モデル

レビュー 1〜2 点を低評価として二値分類しました。

```text
low_review = 1  if review_score <= 2
low_review = 0  if review_score >= 3
```

### 7.1 使用した特徴量

- `注文金額`
- `送料`
- `配送遅延日数`

### 7.2 モデル

- Logistic Regression（ロジスティック回帰）
- StandardScaler を Train データのみに fit
- Train / Validation / Test = 60 / 20 / 20
- Validation 上で F1-score が最大となるしきい値を選択
- threshold = **0.24**

### 7.3 テストデータでの評価結果

| テスト指標 | 結果 |
|---|---:|
| Accuracy | 0.8860 |
| Precision | 0.5919 |
| Recall | 0.3472 |
| F1-score | 0.4377 |
| ROC-AUC | 0.6838 |

Test データでは、低評価 2,448 件のうち 850 件を検出しました。

低評価率は約 12.77% とクラス不均衡があるため、Accuracy だけでなく Precision / Recall / F1 / ROC-AUC を併記しています。

### 7.4 標準化後のオッズ比

| 特徴量 | オッズ比 |
|---|---:|
| 注文金額 | 1.014 |
| 送料 | 1.265 |
| 配送遅延日数 | 2.154 |

今回の3つの特徴量では、配送遅延日数の関連が最も大きいことが分かりました。

### 7.5 このモデルの限界

`delivery_delay_days` は配送完了後に確定する情報です。

そのため、この Baseline モデルは「購入時点の予測モデル」ではなく、**配送完了後〜レビュー投稿前のフォロー対象候補を考えるモデル**として解釈する方が自然です。

Notebook: [`3_predict_low_review.ipynb`](notebooks/3_predict_low_review.ipynb)

### 7.6 時系列Validationによる特徴量改善（旧評価：購入月基準）

将来の注文に対する予測性能を評価するため、時系列によるTrain / Validation / Holdout分割を導入しました。

| データ | 期間 | 注文数 |
|---|---|---:|
| Train | 〜2017年12月 | 43,362 |
| Validation | 2018年1〜4月 | 27,220 |
| Holdout | 2018年5〜8月 | 25,242 |

Holdoutは最終評価まで使用せず、特徴量やしきい値の比較はValidationで実施しています。

注文構成、送料割合、顧客の州、支払い方法、購入月、商品カテゴリ、過去の購買履歴などの特徴量を順次追加しました。

| モデル | Validation F1 | Validation ROC-AUC |
|---|---:|---:|
| Baseline（時系列分割） | 0.5417 | 0.7415 |
| 注文構成・地域・月を追加 | 0.5515 | 0.7661 |
| 支払い特徴量を追加 | 0.5511 | 0.7667 |
| 購入月をsin/cosで表現 | 0.5515 | 0.7670 |
| 商品カテゴリを追加 | 0.5372 | 0.7704 |
| 過去購買履歴を追加 | 0.5366 | 0.7700 |

商品カテゴリの追加によりROC-AUCは若干改善した一方、F1は低下しました。

また、過去の購買履歴の追加による性能改善は限定的でした。

この結果から、特徴量を増やすことが必ずしも予測性能の改善につながるわけではないことが確認されました。

特徴量セットA〜Dを同一のValidation期間で比較した結果、Model AはF1が0.5520、Average Precisionが0.5200となり、両指標で最良でした。そのため、ロジスティック回帰の代表モデルとしてModel Aを選択しました。

なお、これらの結果は購入月を基準とした時系列分割による暫定評価です。

その後、予測時点と評価条件の不整合を確認したため、配送完了日時を基準とし、学習時点でラベルが確定している注文のみを用いる4-Fold時系列CVへ変更しました。

旧評価での高い性能には、配送完了時点ですでにレビュー済みの注文など、現在の予測対象とは異なる注文群が含まれていたことが大きく関係している可能性があります。

現在は新しい評価条件で5モデルと特徴量セットA〜Eを比較し、CatBoost Model Cを主な改善候補としています。

評価条件の変更と最新の比較結果は第9章に記載しています。

Notebook: `11_low_review_feature_engineering.ipynb`、`13_low_review_model_comparison.ipynb`

### 8.5 月別・季節別の商品カテゴリ分析

ブラジルの季節区分:

- 夏: 12月–2月
- 秋: 3月–5月
- 冬: 6月–8月
- 春: 9月–11月

**あるカテゴリが州全体の平均注文額（AOV）にどれくらい寄与しているか**を以下で表します。

```text
平均注文額へのカテゴリ寄与額
= カテゴリGMV / 州全体の注文数
```

さらに、

```text
平均注文額へのカテゴリ寄与額
= カテゴリ購入割合
  × カテゴリGMV / カテゴリ注文数
```

と分解できます。これにより、
「そのカテゴリがよく買われているから寄与が大きいのか（カテゴリ購入割合）」
「そのカテゴリを買ったときの金額が高いから寄与が大きいのか（カテゴリあたりのGMV）」
を分けて検討しています。

![SP州の月別・季節別カテゴリ構成額を拡大](images/SP_Category_AOV_Contribution_Monthly_Seasonal.png)

| 州全体の注文数 | 4,492 | 8,617 |
| カテゴリ購入割合 | 7.48% | 12.17% |
| カテゴリGMV / カテゴリ注文数 | 98.14 | 120.99 |
| AOV 寄与額 | 7.34 | 14.73 |

![SP州のカテゴリ別注文数とGMVの季節別推移](images/SP_Category_Order_Count_and_GMV_Seasonal.png)

このことから、SP州のhealth_beautyは、2018年冬には**より多くの注文で買われるようになり、かつ1注文あたりのカテゴリGMVも高くなった**ため、州全体の平均注文額への寄与が大きくなったと解釈できます。

## 9. 低評価予測モデルの評価設計と今後の開発計画

### 9.1 予測時点の定義

本モデルでは、配送完了時点で、まだレビュー評価が確定していない注文について、その後の低評価リスクを予測することを想定しています。

主な特徴量には注文金額、送料、配送遅延、商品構成、地域情報などを使用します。

配送遅延日数は配送完了後に確定するため、購入時点での予測には使用しません。

### 9.2 時系列クロスバリデーション

配送完了日時を基準としたExpanding Window方式の4-Fold CVを採用しています。

学習には、各Foldの検証開始前に配送が完了し、全有効レビューの回答日時も確定していた注文のみを使用しています。

従来の購入月基準の評価は、予測時点との整合性に課題があったため、現在は診断用の旧結果として扱っています。

最終Holdoutはモデル選択に使用していません。

### 9.3 レビューラベルと予測対象の定義

元のモデルデータ95,824注文について、注文内のすべての有効レビュー回答日時と配送完了日時の関係を確認しました。

| 状態 | 注文数 | 低評価率 |
|---|---:|---:|
| 全レビューが配送完了後 | 87,683 | 8.85% |
| 全レビューが配送完了前 | 4,390 | 77.84% |
| 配送完了前後にまたがる | 105 | 5.71% |
| 回答日時が一部または全部不明 | 3,646 | 28.94% |
| **合計** | **95,824** | **12.77%** |

配送完了時点で未レビューだったことを確認できる87,683件の注文を、現在の主分析対象候補としています。

その他の注文は削除せず、予測対象外候補または日時の判定保留として区別しています。

なお、今回の対象抽出は将来のレビュー回答日時が確認できた注文に限定されています。そのため、実運用時に存在するすべての未レビュー注文を代表するとは限りません。

最初のレビュー1件を用いた予備分類と、全有効レビューを用いた詳細分類の違いについては、`docs/development_log.md` に記録しています。

### 9.4 評価条件の変更による性能差の検証

従来の購入月基準の評価から配送完了日時基準の評価に変更した際、ロジスティック回帰Model AのROC-AUCが低下しました。

そこで、予測対象集団、時系列分割基準、学習時点のラベル確定条件を段階的に変更し、性能差を検証しました。

| 条件 | 変更内容 | ROC-AUC | AP |
|---|---|---:|---:|
| A | 旧対象・購入月基準 | 0.7664 | 0.5200 |
| B | 配送完了後レビュー群に変更 | 0.6476 | 0.2077 |
| C | 配送完了日時基準に変更 | 0.6439 | 0.2132 |
| D | 学習時点のラベル確定条件を追加 | 0.6439 | 0.2130 |

性能低下の大部分はAからBへの変更時に発生しました。

この結果から、従来の高い評価値には、実際の予測対象と異なる注文群を含んでいたことが大きく関係している可能性が示されました。

ただし、学習・検証対象も変化するため、各差分を特定の条件変更による厳密な因果効果とは解釈しません。

### 9.5 5モデルの初期比較

配送完了日時基準の4-Fold CVで、Model Aの特徴量を使用して5つの分類アルゴリズムを比較しました。

| モデル | ROC-AUC平均 | AP平均 |
|---|---:|---:|
| Logistic Regression | **0.6039** | **0.1604** |
| Random Forest | 0.6009 | 0.1507 |
| XGBoost | 0.6012 | 0.1481 |
| LightGBM | 0.5902 | 0.1410 |
| CatBoost | 0.6016 | 0.1483 |

今回の固定パラメータによる初期比較では、ロジスティック回帰が4-Fold平均で最良でした。

一方、Fold 4ではCatBoostがROC-AUC 0.6490、AP 0.2167となり、両指標で最良でした。

本節はModel Aによる5モデルの初期比較です。特徴量比較とCatBoostの調整結果は9.6節に記載しています。

### 9.6 特徴量セットの比較と今後の改善

CatBoostについて、特徴量セットA〜Eを同じ4-Fold CVで比較しました。

| 特徴量 | 平均ROC-AUC | 平均AP |
|---|---:|---:|
| A：基本特徴量 | 0.6016 | 0.1483 |
| B：A＋支払い | 0.6047 | 0.1514 |
| C：B＋商品カテゴリ | 0.6206 | **0.1614** |
| D：C＋修正版顧客履歴 | **0.6216** | 0.1610 |
| E：A＋商品カテゴリ | 0.6188 | 0.1592 |

商品カテゴリの追加による性能改善が確認されました。平均APが最も高いModel Cを、今後のハイパーパラメータ調整の主候補としています。

顧客履歴特徴量は、同一購入日時の注文を考慮した修正版SQLで再評価しています。

#### CatBoost Model Cのハイパーパラメータ調整

Random SearchとGrid Searchによって5パラメータを探索しました。

| Model C | 平均ROC-AUC | 平均AP |
|---|---:|---:|
| 調整前 | 0.6206 | 0.1614 |
| 調整後 | 0.6217 | **0.1757** |

採用候補は `iterations=100`、`depth=3`、`learning_rate=0.02`、`l2_leaf_reg=7`、`random_strength=0.5` です。

4-FoldすべてでAPが改善しました。ただし、繰り返しの探索に使用したCV上の結果であり、最終Holdoutでの性能は未評価です。

#### ランキング評価

調整前後のCatBoost Model Cについて、同じ4-Fold CVで予測確率上位K件の低評価捕捉性能を比較しました。

| 指標 | 調整前 | 調整後 |
|---|---:|---:|
| Precision@100 | 29.75% | **37.50%** |
| Recall@100 | 2.30% | **3.01%** |
| Lift@100 | 3.24倍 | **4.11倍** |

各Foldで100件ずつ選択した場合、4-Fold合計の低評価捕捉数は119件から150件へ増加しました。

これらはモデル選択にも使用したCV上の結果であり、実際の顧客対応による低評価防止効果を示すものではありません。

**今後の予定**

- 予測対象の選択バイアス・レビュー観察期間の検証
- 未使用Holdoutによる最終評価

## 10. 分析上の限界・注意点

- 観察データであり、顧客対応による再購入率・GMVへの因果効果は検証できない
- 州や商品カテゴリによって注文数が異なり、一部の集計は少数観測の影響を受ける
- 季節性の分析期間が短く、安定した季節パターンと断定できない
- 低評価予測はクラス不均衡問題であり、ROC-AUC・APなど複数の指標による評価が必要
- 現在の予測対象は将来レビューが確認された注文に限られ、選択バイアスや観察期間の打ち切りが残る
- モデル選択には4-Fold CVを使用しており、最終Holdout評価は未実施
- GMVは商品価格合計であり、利益や施策の費用対効果を表すものではない
