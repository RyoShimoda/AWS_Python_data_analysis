# AWS_Python_data_analysis

Olist のブラジル EC データを用いて、低評価レビューのリスクを分析・予測し、その要因と将来の購買・GMVとの関係を検証するデータ分析ポートフォリオです。
AWS（Amazon S3 / Athena）と SQL で分析用データを作成し、Python（Positron, VS Code / Jupyter Notebook）で統計分析・機械学習・売上構造分析を行っています。

## 1. 分析で明らかにしたいこと

> **注文・配送・商品・地域情報から低評価になりやすい注文を識別し、
> その要因や対象セグメントを理解したうえで、
> 低評価とその後の再購入・将来 GMV の関係を明らかにできるか。**

本プロジェクトは、次の2段階で進めます。

1. **予測分析**
   - 低評価レビュー（1〜2点）の予測
   - Baseline モデルから追加特徴量を加えた Improved モデルへの改善
   - 将来期間を用いた時系列 Holdout 評価

2. **ビジネスへの影響分析**
   - 低評価 / 高リスク注文と、その後の再購入・注文数・将来 GMV との関係を確認
   - 施策効果そのものではなく、低評価対策が関係しうる売上規模・顧客行動を定量的に把握

> **注意**
> Olist データは観察データであり、介入実験の結果は含まれていません。
> そのため、本プロジェクトでは「施策によって GMV が増加する」といった因果効果は直接推定しません。

現在は以下まで完了しています。

- Customer Experience Analysis
- Baseline 低評価予測モデル
- Train / Validation / Test に分けたモデル評価
- GMV / AOV の基準集計
- 州・カテゴリ・時期・商品構成の探索

評価方法を確定した後、Random Forest・XGBoost・LightGBM・CatBoostなどのモデル比較に進む予定です。

### 6.2 配送遅延とレビュー評価

```text
配送遅延日
= 実際の配送日 - 配送予定日
```

- 負の値: 予定より早く配送
- 0: 予定どおり
- 正の値: 予定より遅く配送

分析対象は 95,830 注文です。

| レビュー評価 | 配送遅延中央値 |
|---:|---:|
| 1 | -7 days |
| 2 | -10 days |
| 3 | -11 days |
| 4 | -12 days |
| 5 | -13 days |

- Kruskal–Wallis: H = 3890.1397, p < 0.001
- ε² = 0.040555
- Dunn 検定では全レビュー評価群間で有意差
- Review 1 vs 5 のペアでは中程度の効果量（δ = 0.3710）を確認

低評価の注文ほど、予定配送日との差が遅延側に位置する傾向が確認されました。

ただし、これは観察データ上の関連であり、配送遅延が低評価を引き起こしたことを示すものではありません。

Notebook: [`2_review_delivery_analysis.ipynb`](notebooks/2_review_delivery_analysis.ipynb)

### 6.3 低評価と90日以内の再購入・将来GMV

レビュー投稿後90日間の購買行動を追跡可能な74,185注文を対象に、低評価と将来の顧客行動の関連を分析しました。

低評価はレビュー評価1〜2点、通常評価は3〜5点と定義しました。

#### 90日以内の再購入率

| 指標 | 通常評価 | 低評価 |
|---|---:|---:|
| 対象注文数 | 63,206 | 10,979 |
| 再購入注文数 | 790 | 104 |
| 再購入率 | 1.2499% | 0.9473% |

Fisherの正確確率検定では、低評価群の再購入率が統計的に有意に低い結果でした。

- オッズ比：0.756
- p値：0.00685
- 再購入率の差：-0.303ポイント

さらに、購入時期・過去注文回数・配送完了状況を調整したロジスティック回帰を実施しました。

同一顧客による複数観測を考慮し、顧客単位のクラスターロバスト標準誤差を使用しました。

- 調整オッズ比：0.742
- 95%信頼区間：0.587〜0.938
- p値：0.0126

調整後も、低評価と90日以内の再購入には統計的に有意な負の関連が認められました。

#### 90日以内の将来GMV

GMVは送料を含まない商品価格合計として集計しました。

| 指標 | 通常評価 | 低評価 |
|---|---:|---:|
| 全注文の平均将来GMV（BRL） | 1.663 | 1.505 |
| 再購入ありの平均将来GMV（BRL） | 133.03 | 158.87 |

将来GMVは約98.8%の注文で0となるため、平均差をブートストラップで評価しました。

顧客単位クラスターブートストラップ（2,000回）の結果：

| 分析対象 | 平均GMV差（低評価−通常評価） | 95%信頼区間 |
|---|---:|---|
| 全注文 | -0.158 BRL | -0.655〜0.430 |
| 再購入あり | +25.843 BRL | -12.247〜73.609 |

いずれも95%信頼区間に0を含み、平均将来GMVの明確な群間差は確認できませんでした。

#### ビジネス上の示唆

低評価はその後の再購入率と負の関連を示しており、低評価リスクを早期に検知するモデルは、顧客フォロー対象の優先順位付けに活用できる可能性があります。

一方、将来GMVとの明確な関連は確認できていません。

これらは観察データ上の関連であり、低評価への介入によって再購入率や売上が改善するという因果効果を示すものではありません。

Notebook: `12_low_review_future_purchase_analysis.ipynb`

## 7. 低評価予測の基準モデル

レビュー 1〜2 点を低評価として二値分類しました。

```text
low_review = 1  if review_score <= 2
low_review = 0  if review_score >= 3
```

### 使用した特徴量

- `注文金額`
- `送料`
- `配送遅延日数`

### モデル

- Logistic Regression（ロジスティック回帰）
- StandardScaler を Train データのみに fit
- Train / Validation / Test = 60 / 20 / 20
- Validation 上で F1-score が最大となるしきい値を選択
- threshold = **0.24**

### テストデータでの評価結果

| テスト指標 | 結果 |
|---|---:|
| Accuracy | 0.8860 |
| Precision | 0.5919 |
| Recall | 0.3472 |
| F1-score | 0.4377 |
| ROC-AUC | 0.6838 |

Test データでは、低評価 2,448 件のうち 850 件を検出しました。

低評価率は約 12.77% とクラス不均衡があるため、Accuracy だけでなく Precision / Recall / F1 / ROC-AUC を併記しています。

### 標準化後のオッズ比

| 特徴量 | オッズ比 |
|---|---:|
| 注文金額 | 1.014 |
| 送料 | 1.265 |
| 配送遅延日数 | 2.154 |

今回の3つの特徴量では、配送遅延日数の関連が最も大きいことが分かりました。

### このモデルの限界

`delivery_delay_days` は配送完了後に確定する情報です。

そのため、この Baseline モデルは「購入時点の予測モデル」ではなく、**配送完了後〜レビュー投稿前のフォロー対象候補を考えるモデル**として解釈する方が自然です。

Notebook: [`3_predict_low_review.ipynb`](notebooks/3_predict_low_review.ipynb)

### 時系列Validationによる特徴量改善

将来の注文に対する予測性能を評価するため、時系列によるTrain / Validation / Holdout分割を導入しました。

| データ | 期間 | 注文数 |
|---|---|---:|
| Train | 〜2017年12月 | 43,362 |
| Validation | 2018年1〜4月 | 27,220 |
| Holdout | 2018年5〜8月 | 25,242 |

Holdoutは最終評価まで使用せず、特徴量やしきい値の比較はValidationで実施しています。

注文構成、送料割合、顧客の州、支払い方法、購入月、商品カテゴリ、過去購買履歴などの特徴量を順次追加しました。

| モデル | Validation F1 | Validation ROC-AUC |
|---|---:|---:|
| Baseline（時系列分割） | 0.5417 | 0.7415 |
| 注文構成・地域・月を追加 | 0.5515 | 0.7661 |
| 支払い特徴量を追加 | 0.5511 | 0.7667 |
| 購入月をsin/cosで表現 | 0.5515 | 0.7670 |
| 商品カテゴリを追加 | 0.5372 | 0.7704 |
| 過去購買履歴を追加 | 0.5366 | 0.7700 |

商品カテゴリの追加によりROC-AUCは若干改善した一方、F1は低下しました。

また、過去購買履歴の追加による性能改善は限定的でした。

この結果から、特徴量を増やすことが必ずしも予測性能の改善につながるわけではないことが確認されました。

特徴量セットA〜Dを同一のValidation期間で比較した結果、Model AはF1が0.5520、Average Precisionが0.5200となり、両指標で最良でした。そのため、ロジスティック回帰の代表モデルとしてModel Aを選択しました。

なお、これらの結果は購入月を基準とした時系列分割による暫定評価です。

その後の検証で、予測時点である配送完了日時と購入月が一致しない注文が約37.7%存在することが判明しました。このため、現在は配送完了日時を基準とした評価方法を検討しています。

新しい評価設計を確定した後、各モデルを同じ条件で比較し、未使用のHoldoutで最終評価する予定です。

### 8.5 月別・季節別の商品カテゴリ分析

ブラジルの季節区分:

- 秋: 3月–5月

- 春: 9月–11月

**あるカテゴリが州全体の平均注文額（AOV）にどれくらい寄与しているか**を以下で表します。

```text
平均注文額へのカテゴリ寄与額
= カテゴリGMV / 州全体の注文数
```

さらに、

```text
平均注文額へのカテゴリ寄与額
= カテゴリ購入割合
  × カテゴリGMV / カテゴリ注文数
```

と分解できます。これにより、
「そのカテゴリがよく買われているから寄与が大きいのか（カテゴリ購入割合）」
「そのカテゴリを買ったときの金額が高いから寄与が大きいのか（カテゴリあたりのGMV）」
を分けて検討しています。

| カテゴリGMV / カテゴリ注文数 | 98.14 | 120.99 |
| AOV 寄与額 | 7.34 | 14.73 |

## 9. 低評価予測モデルの評価設計と今後の開発計画

### 9.1 予測時点の定義

本モデルでは、配送完了時点で、まだレビュー評価が確定していない注文について、その後の低評価リスクを予測することを想定しています。

主な特徴量には注文金額、送料、配送遅延、商品構成、地域情報などを使用します。

配送遅延日数は配送完了後に確定するため、購入時点での予測には使用しません。

### 9.2 時系列クロスバリデーション

予測性能の時間的な安定性を検証するため、Expanding Window方式の時系列クロスバリデーションを導入しました。

購入月基準の3-Fold CVでは、ロジスティック回帰のROC-AUCが0.628〜0.741の範囲で変化しました。

一方、購入月と配送完了月が異なる注文が36,091件（約37.7%）存在することが判明したため、現在は配送完了日時に基づく評価設計を検討しています。

また、従来の2018年1〜4月のValidation期間についても、すでにモデル選択に使用していることから、Fold 4として組み込む方針を検討しています。

最終Holdoutはモデル選択に使用せず、最終評価用として保持します。

### 9.3 レビューラベルと予測時点の整合性

レビュー回答日時を用いた予備分析では、95,824注文について次の結果となりました。

| 状態 | 注文数 |
|---|---:|
| 配送完了前にレビュー回答 | 4,502 |
| 配送完了後にレビュー回答 | 87,709 |
| 回答日時が不明 | 3,613 |

上記は、注文ごとの最初の有効なレビュー回答日時を用いた予備分析の結果です。

その後、注文内のすべての有効レビューを対象として、回答日時と配送完了日時の前後関係を再集計しました。

| 状態 | 注文数 | 低評価率 |
|---|---:|---:|
| すべてのレビューが配送完了後 | 87,683 | 8.85% |
| すべてのレビューが配送完了前 | 4,390 | 77.84% |
| 配送完了前後にまたがる | 105 | 5.71% |
| レビュー回答日時が一部または全部不明 | 3,646 | 28.94% |
| **合計** | **95,824** | **12.77%** |

複数レビュー注文の前後関係や回答日時の欠損を考慮した結果、予備分析とは分類件数が異なりました。

現在の配送完了時点における低評価予測モデルでは、すべての有効レビューが配送完了後に回答された87,683注文を主分析の対象候補としています。

なお、この対象には将来レビューが回答されたことが確認できた注文のみが含まれるため、実運用時の全未レビュー注文を代表するとは限りません。

87,683注文を対象候補として配送完了日時基準の4-Fold時系列CVを構築し、学習時点で全レビューの回答が完了している注文のみを学習に使用しました。

ロジスティック回帰Model Aの4-Fold平均は、ROC-AUCが0.6039、Average Precisionが0.1604でした。

従来の購入月基準の評価より性能は低下していますが、対象集団・分割基準・学習ラベルの利用可能条件を同時に変更しているため、原因は未確定です。

### 9.4 今後のモデル比較

時系列評価と予測対象条件を確定した後、以下のモデルを比較する予定です。

- Logistic Regression
- Random Forest
- XGBoost
- LightGBM
- CatBoost
- 必要に応じてニューラルネットワーク

モデル比較ではROC-AUC、Average Precision、Precision、Recall、F1などを確認します。

さらに、ハイパーパラメータ調整や確率平均アンサンブル、時系列Out-of-Fold予測を用いたスタッキングについても検証を予定しています。

最終的には、選択したモデルを未使用のHoldoutで評価し、低評価リスクの高い注文の優先順位付けへの活用可能性を検討します。

## 10. 低評価とその後の購買・売上との関係分析

低評価予測モデルのビジネス上の意義を検討するため、レビュー投稿後90日間の再購入・将来GMVとの関連を分析しました。

分析では、`customer_unique_id` を使って同一顧客の将来注文を追跡しました。

主な指標：

- 90日以内再購入率
- 90日以内の注文回数
- 90日以内の将来GMV

### 分析結果の概要

低評価群は通常評価群より90日以内の再購入率が低く、購入時期・過去注文回数・配送完了状況を調整した後も負の関連が認められました。

一方、将来GMVについては、顧客単位クラスターブートストラップによる分析でも明確な群間差を確認できませんでした。

詳細な結果は「6.3 低評価と90日以内の再購入・将来GMV」に記載しています。

### 想定する活用方法

低評価リスクが高い注文を早期に検知し、顧客フォロー対象の優先順位付けに利用することを検討しています。

ただし、今回の結果は観察データ上の関連であり、予測モデルに基づく介入施策の効果を直接示すものではありません。

売上改善効果を確認するためには、実際の顧客フォロー施策について追加の効果検証が必要です。

## 11. 分析上の限界・注意点

- 観察データのため、因果効果は直接推定できない
- GMV は商品価格合計であり、原価・広告費・販売手数料等を含まない
- 利益への効果は評価できない
- Baseline モデルの配送遅延日数は配送後情報
- 低評価は 12.77% でクラス不均衡がある
- 州によって注文数が大きく異なる
- 小規模州では少数注文の影響が大きい
- 商品カテゴリには `uncategorized` が存在する
- 季節性は十分な年数を繰り返し観測していないため確定できない
- 従来の時系列モデル評価は購入月を基準としており、配送完了時点での運用を厳密に再現したものではない
- 購入月と配送完了月が異なる注文が存在するため、評価期間の再設計が必要
- レビュー回答日時が不明な注文や、配送完了前にレビューされた注文が存在する
- 注文単位で複数レビューを集約しているため、ラベルが利用可能になった時点の確認が必要
- 従来の時系列CVおよびValidationの性能は暫定的な評価結果であり、最終的な汎化性能は未使用のHoldoutで評価する
